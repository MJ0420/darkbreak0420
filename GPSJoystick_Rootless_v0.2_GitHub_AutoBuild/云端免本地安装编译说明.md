# GPS Joystick v0.2 自动编译包（GitHub Actions）

**这个 ZIP 是源码与自动编译配置，不是已经编译好的 .deb。**

## 目的

如果你不想在 Windows 或 Mac 上安装 Theos / iOS SDK / 签名工具，可以使用 GitHub Actions 的 Mac 云端机器执行编译。成功时 GitHub 会提供包含 `.deb` 的下载档案。**不需要自己的 Apple 开发者证书，也不需要 SideStore 签名。** 云端会安装所需的 Theos、Xcode SDK、ldid / dpkg 打包工具。

## 操作（没有本地编译环境也可以）

1. 打开 https://github.com/new ，新建一个 **Private** 仓库，默认分支选 `main`。
2. 解压本 ZIP，把**解压后文件夹里的所有内容**（包括 `.github/workflows/build-deb.yml`、`Makefile`、`overlay`、`src`、`tests`、`control`）放到仓库**根目录**。注意：直接上传 ZIP 文件本身不会触发源码编译。可通过 GitHub Desktop 将整个目录提交上传；或网页端上传解压后的文件和文件夹。
3. 进入仓库的 **Actions** 标签，找到 **Build GPS Joystick Rootless DEB**，运行 `Run workflow`；首次 push 到 `main` 也会自动尝试编译。
4. 只有绿色成功标记时，打开该次运行页面底部 **Artifacts → GPSJoystick-rootless-deb** 下载。
5. 下载的 Artifact 是一个 ZIP，解压才会得到 `.deb`。传输到越狱 iPhone，用 Sileo/Filza 安装前仔细阅读下方风险。

如果 Actions 报错/失败，不会有可安装 `.deb`。打开失败日志并保存错误信息。**本项目至今没有在 iPhone 7 Plus / iOS 15.8.8 上完成真实编译与安装验证，云端成功编译也不等于插件正常工作。**

## 首次安装风险与回退

- 此版本会注入 **SpringBoard 和 Apple Maps**，SpringBoard 崩溃可能导致重复 Respring 或安全模式；务必先确认 Dopamine Safe Mode 和卸载途径可用。
- 不保证小浮窗覆盖所有 App、Apple Maps 回调持续变化，或影响系统级定位；它仍是技术原型。
- 同一时间只运行一个定位引擎，先关闭 GPS Master 的模拟定位。
- 恢复按钮仅清除本插件模拟状态，不会替其他定位软件清除位置。
- 这是 Rootless 测试包，不要在未越狱 iPhone 或主要日用设备上安装。不要期待解决 Pokémon GO Error 12。
- 如出现桌面崩溃，进入 Dopamine Safe Mode 并在 Sileo 卸载 `com.mj.gpsjoystick`；如不熟悉安全模式，不建议安装。
